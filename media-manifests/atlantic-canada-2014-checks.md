# Атлантическая Канада, 2014 — проверка переноса

Источник: `Отчеты/2014_ Атлантическая Канада.docx`.

- Созданы 16 отдельных глав: планирование, дни 1–14, заключение.
- Автоматически сверены все 16 исходных заголовков и 228 текстовых абзацев. Слова, опечатки, пунктуация и последовательность текста сохранены; исходные HTML-теги жирного и зачёркнутого текста отображаются как форматирование.
- Все 300 вхождений фотографий сохранены в исходном порядке и на исходных местах между абзацами. В соответствии с актуальным `TEAM_HANDOFF.md` из `81a96e5` отменены прежние перемещения 12 снимков через текст. Соседние кадры объединены в 139 линеек. В реестре `order` и `displayOrder` совпадают; `sourceParagraph` — номер абзаца DOCX, начиная с нуля.
- В архиве 300 выбранных фотографий, 153 489 400 байт, включая три восстановленных пользователем снимка. Проверены размеры файлов и SHA-256 всех выбранных оригиналов. Три дополнительные точные копии восстановленных фотографий сохранены как `zz_не использовано_…`, зарегистрированы в `unusedPhotos`, не удалены.
- Архив остаётся по прямо указанному владельцем пути: `G:\My Drive\Family Travel Blog Photos\North America\2014 - Атлантическая Канада`. В нём 16 папок `01 - …` — `16 - …` с русскими названиями, без подпапок. Файлы названы `NN_<исходное имя>` по порядку в главе. Реестры: `photo-manifest.json`, `photo-order.csv`, `unavailable-photos.md`, `links-check.json`, `drive-images-check.json`.
- Исходные имена сохранены после числового префикса и отдельно в `originalFilename`. У ссылок без имени оно получено из HTTP Content-Disposition; искусственных имён нет.
- Архив содержит полные доступные оригиналы `/d/` и `=d`. Для шести ссылок Google Photos прежний `=s0` заменён на `=d`, контрольные суммы этих шести файлов также сверены с оригиналами непосредственно в облаке Drive. Искусственного увеличения изображений нет. Пять иллюстраций из исходного рассказа имеют небольшой исходный размер: карта 400×445, туристическое фото прилива 500×375, два снимка из соцсети 720×540 и 540×720, интернет-иллюстрация 560×363.
- Все три ранее недоступных снимка восстановлены: `IMG_4220.JPG` (день 3), `IMG_4512.JPG` (день 7), `IMG_4573.JPG` (день 8). Они вставлены в исходные позиции через проверенные ссылки Google Drive. Все имеют размер 2816×1584. `IMG_4220.JPG` установлен обложкой всей поездки. Недоступных фотографий больше нет.
- Проверены 22 текстовые ссылки, включая исходные ссылки на главы LiveJournal: 19 открываются, 3 возвращают 404. Ошибки соединения с LiveJournal устранены повторной проверкой через HTTPS. Исходные адреса в тексте не изменены.

Для всех 16 глав выбраны горизонтальные `hero_image` с `w2000`; для планирования и заключения использованы подходящие фотографии этой поездки. По локальному индексу Drive подтверждены актуальные пути и облачные ID всех 300 выбранных файлов; идентификаторов `local…` нет. - Все 16 страниц глав, страница поездки, Канады, 2014 года, главная страница и связанные места проверены по HTML локального сервера. Проверены отображаемые заголовки, дословность видимых абзацев, порядок всех снимков и исходные границы абзацев после свежего чтения DOCX. Команда проверки: `node scripts/verify-atlantic-canada-2014.cjs`. `npm run build` проходит: 281 страница на текущем совместном состоянии проекта.
