# Инструкции проекта

Перед работой прочитать `AGENTS.md`, `TEAM_HANDOFF.md`, `NEW_TRIPS_WORKFLOW.md` и `DESIGN_PHOTOS.md`.

Для нового путешествия обязательна последовательность: **полные оригиналы в правильно организованном архиве Drive → проверка файлов, реестра и облачной синхронизации → экранные копии → загрузка и проверка R2 → проверка сайта**. Архив Drive — основной источник для будущего переноса; R2 хранит копии для показа на сайте. Оба этапа входят в задачу добавления поездки.

Не считать поездку готовой без одного из этих этапов. Не включать изменения другого агента в свой коммит; текущие указания владельца имеют приоритет.
